# Archived ECG amplitude representation study

This directory preserves the first research phase of the repository.

The study began as a focused investigation of whether global record-wise z-score standardization changes ECG classification performance differently for PTB-XL hypertrophy and myocardial infarction phenotypes.

The study was developed through a protocol, data and waveform audits, methods literature review, implementation tests, a statistical analysis plan and an OSF preregistration draft. The primary held-out model analysis was not run.

A deeper literature review later showed substantial overlap between the central question and recent ECG work. Several narrower extensions were checked as well, but the additional literature did not leave a sufficiently clean standalone research question. The project was therefore superseded rather than extended indefinitely.

The files in this archive are preserved as they existed at the end of that phase. They are not the current research protocol.

The original study citation metadata are preserved in [CITATION.cff](CITATION.cff).

Start with [01 STUDY PROTOCOL.md](01%20STUDY%20PROTOCOL.md), then read the numbered documents in order. [13 RESEARCH LOG.md](13%20RESEARCH%20LOG.md) contains the original study history.

The project-level transition is recorded in the root [13 RESEARCH LOG.md](../../13%20RESEARCH%20LOG.md).
