# Literature review

This file will record the papers reviewed before the main analysis.

For each paper, record

- citation
- dataset
- preprocessing or normalization
- diagnostic task
- model
- evaluation split
- metrics
- main finding
- limitation
- relevance to this study

The first literature pass will cover the PTB-XL dataset paper, recent work on ECG preprocessing and normalization, recent studies of preprocessing effects on PTB-XL, and literature relevant to amplitude-dependent ECG interpretation.

The purpose of the review is to narrow the question before implementation rather than to provide a broad review of ECG machine learning.
