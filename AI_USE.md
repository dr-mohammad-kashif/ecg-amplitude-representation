# AI use

AI tools will be used throughout this project for literature discovery, code drafting, debugging, documentation and methodological challenge.

AI output is not treated as evidence or as the final decision-maker.

For each substantial use of AI, record what it contributed and what was checked independently.

A useful entry records

- date
- task
- tool or model
- suggestion or generated material
- verification step
- final decision
- reason for accepting, changing or rejecting the suggestion

For code, the final implementation should be tested from a clean environment where practical.

For scientific claims, the underlying paper, dataset documentation or analysis output should be checked directly.

The purpose of this file is to keep the research process transparent, including cases where an AI suggestion was wrong or was not used.
